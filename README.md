Console Game in C#

This is a simple turn-based console game written in C#.  
The entire game runs inside a single `Program.cs` file.

### 🎯 Goal
The purpose of this project is to practice C# fundamentals such as:
- Classes and objects
- Methods and basic game logic
- Conditional statements and loops
- Console input/output
- Random number generation

No external files or libraries are used – everything happens inside the console.

Built using JetBrains Rider.
